## Verdict (read this first)

**v5 pain messaging is half-right for CRE.**

| What holds for CRE | What over-indexes residential |
|--------------------|-------------------------------|
| CRM rot / manual entry (Reddit) | “Trash leads” / Zillow / Follow Up Boss volumes |
| Portal lead quality (LoopNet scams) | “Buy real estate leads” / Premier Agent language |
| Ads expensive without follow-through | Realtor dialer / 300-calls burnout as primary frame |
| Need one system that runs the desk | Category “AI agent” (CRE AI vol ≈ 90/mo) |

**CRE search language (Semrush) is tool/category, not rant:**  
`commercial real estate software` · `CRE CRM` · `CRE marketing` · `prospecting` · `deal management` · `CRE leads` · brand nav (LoopNet / Reonomy / Buildout / Dealpath / Catylist).

**Implication:** Keep pain honesty, but **de-residentialize the hero** and **add CRE-native intent terms** (CRM, marketing, prospecting, deal management, portal noise) so CRE brokers recognize themselves in search and on the page.

## 4. Approaches (pick one — brainstorming gate)

### Approach A — Dual-audience, de-residentialized (recommended)

One waitlist. Hero pain language that works for **CRE + residential** without Zillow/FUB. Secondary lines use CRE Semrush terms (CRM, marketing, prospecting, deal management).

- **Pros:** Matches locked “same message” decision; fixes CRE recognition gap  
- **Cons:** Slightly less viral “trash leads” snap for residential  
- **Sample hero:** `Stop losing deals to portal noise and slow follow-up.`  
- **Sub:** `LoopNet leftovers. Expensive ads. CRMs that rot. One agent for CRE marketing, prospecting, and deal follow-through — commercial and residential.`

### Approach B — CRE-primary waitlist

Hero and SEO language optimized for CRE CRM / software / marketing. Residential mentioned as “also.”

- **Pros:** Highest CRE search-intent alignment; clearer vs Buildout/Dealpath  
- **Cons:** Breaks “same message” for residential; smaller TAM on-page  

### Approach C — Segmented pages

`/waitlist` dual + `/cre` CRE-native (Semrush cluster) later.

- **Pros:** Best of both for SEO  
- **Cons:** Two specs, more build; premature for Mercury waitlist  

**Recommendation:** **Approach A** now; keep Approach C as post-waitlist SEO option.
